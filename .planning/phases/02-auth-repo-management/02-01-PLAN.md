    - Test: getDeleteCounts(repoId) returns accurate commit and PR counts for a repo
    - Test: deleteRepoData(repoId) removes commits, PRs, collection_state, and the repo row
    - Test: deleteRepoData(repoId) removes orphaned authors but preserves authors referenced by other repos

  <action>
    **src/server/services/repo-management.ts** — Import `db` from `../db/client.js`, all tables from `../db/schema.js`, and operators `{ eq, isNull, isNotNull, sql }` from `drizzle-orm`. Export these functions:

    1. `getTrackedRepos()` — `db.select().from(repositories).where(isNull(repositories.removedAt)).all()`
    2. `getStoppedRepos()` — `db.select().from(repositories).where(isNotNull(repositories.removedAt)).all()`
    3. `addRepos(repos: Array<{githubId, fullName, name, ownerLogin, isPrivate, defaultBranch}>)` — loop over repos, for each call `db.insert(repositories).values({ ...repo, addedAt: new Date(), removedAt: null }).onConflictDoUpdate({ target: repositories.githubId, set: { removedAt: null, addedAt: new Date() } }).run()`
    4. `stopTracking(id: number)` — `db.update(repositories).set({ removedAt: new Date() }).where(eq(repositories.id, id)).run()`
    5. `getDeleteCounts(repoId: number)` — returns `{ commits: number, prs: number }` by running count queries on commits and pullRequests tables filtered by `eq(*.repoId, repoId)`
    6. `deleteRepoData(repoId: number)` — deletes in order: collectionState, commits, pullRequests (all where repoId matches), then orphaned authors via raw SQL `DELETE FROM authors WHERE id NOT IN (SELECT DISTINCT author_id FROM commits WHERE author_id IS NOT NULL) AND id NOT IN (SELECT DISTINCT author_id FROM pull_requests WHERE author_id IS NOT NULL)`, then finally the repositories row

    Define these endpoints:

    1. **GET /api/repos/available** (per AUTH-03, D-03):
       - Call `createOctokit()` — if null, return `c.json({ error: 'GitHub token not configured' }, 401)`
       - Call `getAuthenticatedLogin(octokit)` to get the user's login (for personal repo grouping per Pitfall 6)
       - Call `listAllRepos(octokit)` to get all repos
       - Map each repo to `{ githubId: r.id, fullName: r.full_name, name: r.name, ownerLogin: r.owner.login, isPrivate: r.private, defaultBranch: r.default_branch }`
       - Return `c.json({ repos: [...], authenticatedLogin: user.login })`
       - Wrap in try/catch, return `c.json({ error: 'GitHub API error: ...' }, 502)` on failure

    2. **GET /api/repos** (tracked repos):
       - Call `getTrackedRepos()` and return `c.json({ repos: [...] })`

    3. **GET /api/repos/stopped** (stopped repos for management panel):
       - Call `getStoppedRepos()` and return `c.json({ repos: [...] })`

    4. **POST /api/repos** (per AUTH-04, D-09):
       - Zod schema: `z.object({ repos: z.array(z.object({ githubId: z.number(), fullName: z.string(), name: z.string(), ownerLogin: z.string(), isPrivate: z.boolean(), defaultBranch: z.string().default('main') })) })`
       - Parse body, validate, call `addRepos(parsed.data.repos)`
       - Return `c.json({ success: true })`

    5. **PATCH /api/repos/:id/stop** (per AUTH-05, D-11):
       - Parse `id` from params as integer
       - Call `stopTracking(id)`
       - Return `c.json({ success: true })`

    6. **GET /api/repos/:id/delete-preview** (per AUTH-06, D-12):
       - Parse `id` from params
       - Call `getDeleteCounts(id)`
       - Return `c.json({ commits: N, prs: N })`

    7. **DELETE /api/repos/:id** (per AUTH-06, D-12):
       - Parse `id` from params
       - Call `deleteRepoData(id)`
       - Return `c.json({ success: true })`
