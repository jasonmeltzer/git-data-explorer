    Create `src/server/services/collection-engine.ts` as a class-based service:

    **CollectionEngine class:**
    - Private fields: `_listeners: Set<(event: CollectionProgressEvent) => void>`, `_aborted: boolean`, `_rateLimitResetAt: Date | null`, `_rateLimitWaitTimer: NodeJS.Timeout | null`
    - `addProgressListener(fn)` / `removeProgressListener(fn)` — for SSE streaming
    - `emitProgress(event: CollectionProgressEvent)` — broadcasts to all listeners
    - `abort()` — sets `_aborted = true` to stop the loop on next page boundary

    **collectRepo(octokit, repo: { id, fullName, ownerLogin, name, defaultBranch }) method:**
    - Emits `repo_start` event
    - Calls `collectCommits(octokit, repo)` then `collectPRs(octokit, repo)`
    - Catches `RateLimitError` (custom class thrown from modified octokit callbacks) — calls `markCollectionPaused`, emits `rate_limit` event, schedules auto-resume timer via `setTimeout`
    - On completion, emits `repo_complete` event
    - On error (non-rate-limit), calls `upsertCollectionState` with status='error', emits `error` event

    **collectCommits(octokit, repo) private method (per D-07 — raw /commits endpoint):**
    - Read existing cursor from `getCollectionState(repo.id, 'commits')`
    - Use `octokit.paginate.iterator(octokit.rest.repos.listCommits, { owner: repo.ownerLogin, repo: repo.name, per_page: 100, ...(cursor ? { since: cursor } : {}) })`
    - For each page:
      - Check `_aborted` flag — if true, checkpoint and return early
      - For each commit in page:
        - Extract author login from `commit.author?.login` or `commit.commit.author?.name` (fallback)
        - Upsert author to `authors` table with `isBot` from `isBot(login, commit.author?.type)`, update `firstCommitAt` if this commit is earlier
        - Check if `commit.stats` is present (additions/deletions). If stats is null/undefined on the first commit of the page, set a flag `needsIndividualStats = true`
        - If `needsIndividualStats`, fetch `octokit.rest.repos.getCommit({ owner, repo, ref: commit.sha })` for stats
        - Upsert to `commits` table using `onConflictDoUpdate` on `(sha, repoId)` — update linesAdded, linesDeleted, filesChanged if they were 0
      - After writing page: `upsertCollectionState(repo.id, 'commits', { cursor: lastCommitDate, status: 'in_progress', lastPage: pageNumber })`
      - Emit `page_complete` event with itemsInPage and totalItemsSoFar
    - On loop exit: `markCollectionComplete(repo.id, 'commits')`

    **collectPRs(octokit, repo) private method:**
    - Read existing cursor from `getCollectionState(repo.id, 'pull_requests')`
    - Use `octokit.paginate.iterator(octokit.rest.pulls.list, { owner: repo.ownerLogin, repo: repo.name, state: 'all', sort: 'updated', direction: 'asc', per_page: 100 })`
    - For each page:
      - Check `_aborted` flag
      - For each PR:
        - If cursor exists and `pr.updated_at <= cursor`, skip (already collected)
        - Fetch full PR: `octokit.rest.pulls.get({ owner, repo, pull_number: pr.number })` to get additions, deletions, changed_files, commits count
        - Upsert author (same as commits)
        - Upsert to `pullRequests` table using `onConflictDoUpdate` on `(githubId, repoId)`
      - If all PRs in page were skipped (all <= cursor), break pagination
      - Checkpoint: `upsertCollectionState(repo.id, 'pull_requests', { cursor: lastUpdatedAt, status: 'in_progress', lastPage: pageNumber })`
      - Emit `page_complete` event
    - On loop exit: `markCollectionComplete(repo.id, 'pull_requests')`

    **Rate-limit handling:**
    - Create a custom `RateLimitError` class with `retryAfter: number` and `isSecondary: boolean` fields
    - The collection engine does NOT modify the global octokit callbacks. Instead, it creates a separate Octokit instance via `createCollectionOctokit()` that throws `RateLimitError` from the callbacks instead of logging:
      - `onRateLimit`: throw new RateLimitError(retryAfter, false) — so the paginate iterator stops
      - `onSecondaryRateLimit`: throw new RateLimitError(retryAfter || 60, true)
    - The catch block in `collectRepo` handles these: records pause state, emits event, sets auto-resume timer (D-14)

    **Auto-resume (D-14):**
    - `scheduleResume(retryAfterMs: number)` — stores a `setTimeout` reference. When timer fires, calls the queue's resume method.
    - For secondary rate limits, use `Math.max(retryAfter, 60) * 1000 + 2000` (60s minimum per GitHub docs + 2s buffer)

    **Author upsert helper:**
    ```typescript
    function upsertAuthor(login: string, name: string | null, userType: string | null, commitDate: Date): number {
      const bot = isBot(login, userType);
      db.insert(authors)
        .values({ githubLogin: login, name, isBot: bot, firstCommitAt: commitDate })
        .onConflictDoUpdate({
          target: authors.githubLogin,
          set: {
            name: sql`COALESCE(excluded.name, ${authors.name})`,
            isBot: bot,
            firstCommitAt: sql`MIN(${authors.firstCommitAt}, excluded.first_commit_at)`,
          },
        })
        .run();
      // Return author id
      const row = db.select({ id: authors.id }).from(authors).where(eq(authors.githubLogin, login)).get();
      return row!.id;
    }
    ```

    **2. Hono routes** — Create `src/server/routes/collection.ts`:

    ```typescript
    import { Hono } from 'hono';
    import { streamSSE } from 'hono/streaming';
    import { z } from 'zod';
    import { CollectionQueue } from '../services/collection-queue.js';

    const collection = new Hono();

    // Singleton queue instance
    const queue = new CollectionQueue();

    // POST /api/collection/start — start batch or specific repos
    // Body: { repoIds?: number[] }
    collection.post('/api/collection/start', async (c) => {
      const body = await c.req.json().catch(() => ({}));
      const schema = z.object({ repoIds: z.array(z.number()).optional() });
      const parsed = schema.safeParse(body);
      if (!parsed.success) return c.json({ error: 'Invalid request' }, 400);
      await queue.startBatch(parsed.data.repoIds);
      return c.json({ started: true });
    });

    // POST /api/collection/stop — stop all collection
    collection.post('/api/collection/stop', (c) => {
      queue.stopAll();
      return c.json({ stopped: true });
    });

    // POST /api/collection/skip — skip current repo
    collection.post('/api/collection/skip', (c) => {
      queue.skipCurrent();
      return c.json({ skipped: true });
    });

    // GET /api/collection/status — current batch status (polling fallback)
    collection.get('/api/collection/status', (c) => {
      return c.json(queue.getStatus());
    });

    // GET /api/collection/resume-info — check if there are incomplete collections (D-16)
    collection.get('/api/collection/resume-info', (c) => {
      return c.json(queue.getIncompleteForResume());
    });

    // GET /api/collection/progress — SSE stream for live progress (D-06)
    collection.get('/api/collection/progress', (c) => {
      return streamSSE(c, async (stream) => {
        const listener = (event: CollectionProgressEvent) => {
          stream.writeSSE({
            data: JSON.stringify(event),
            event: 'progress',
            id: String(Date.now()),
          });
        };
        stream.onAbort(() => queue.removeProgressListener(listener));
        queue.addProgressListener(listener);

        // Send current status immediately as first event
        const status = queue.getStatus();
        await stream.writeSSE({
          data: JSON.stringify({ type: 'status_snapshot', ...status }),
          event: 'status',
          id: String(Date.now()),
        });

        // Hold connection open while collection is active
        // Use a Promise that resolves when batch completes or client disconnects
        await new Promise<void>((resolve) => {
          const checkDone = (event: CollectionProgressEvent) => {
            if (event.type === 'batch_complete') {
              resolve();
            }
          };
          queue.addProgressListener(checkDone);
          stream.onAbort(() => {
            queue.removeProgressListener(checkDone);
            resolve();
          });
        });
      });
    });

    export default collection;
    ```
