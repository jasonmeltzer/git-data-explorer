## Decisions Made
- Used Drizzle query builder (from analytics-rampup pattern) as canonical implementation for shared getCompleteRepoIds, since it's more type-safe than raw sql template
- Added SEC-01 integer guard to the shared implementation — filter to only positive integers before any sql.raw downstream usage
- drizzle-kit esbuild advisory left as accepted dev-only risk: our version (0.31.10) is above the affected range (0.17.x-1.0.0-beta), but npm registry metadata is stale. `--force` would downgrade to 0.18.1 (incompatible), so this is explicitly documented as accepted risk
